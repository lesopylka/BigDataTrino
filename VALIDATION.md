# Контейнерная проверка

Дата проверки 13 ноября 2026.

[Успешный прогон GitHub Actions](https://github.com/lesopylka/BigDataTrino/actions/runs/43434432463).

Проверены реальные коннекторы PostgreSQL и ClickHouse, объединение источников, построение модели, шесть витрин и повторный ETL. Результаты сверены с CSV.

Контрольные значения после каждого расчета или повторной доставки

- 10000 уникальных продаж
- 54623 единицы товара
- Сумма 2529852.12

Исходные файлы содержат по 1000 строк, всего 10 CSV. Сборка и проверка выполняются на чистом Ubuntu runner через Docker Compose, без подмены сервисов. Команды воспроизводятся из [.github/workflows/integration.yml](.github/workflows/integration.yml).

Каталог ClickHouse использует `clickhouse.map-string-as-varchar=true`. Средний чек рассчитывается как `AVG(CAST(sale_total_price AS DOUBLE))`, чтобы Trino не округлял промежуточное среднее DECIMAL до двух знаков. Суммы продаж сохраняют исходный денежный тип.
